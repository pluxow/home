# Pluxow — Notas para Claude

Este repo es el sitio web y material de marca de Pluxow. Antes de trabajar acá, tené en cuenta las notas técnicas y de proceso que ya existen — evitan repetir decisiones ya tomadas.

## Índice de notas

- `PROJECT_SUMMARY.md` — resumen del proyecto web (stack, estructura, secciones, servicios).
- `arquitectura-supabase.md` — cómo se organizan los proyectos de clientes en Supabase (1 proyecto, 1 schema por cliente) y cómo conectar desde n8n / CRM.
- `arquitectura-whatsapp-clientes.md` — cómo dar de alta WhatsApp Business API para un cliente nuevo: número y WABA propios por cliente, modelo de facturación (Tech Provider), coexistence vs. número dedicado, deadlines de Meta a vigilar.
- `content/carruseles-proceso.md` — proceso end-to-end para armar carruseles de Instagram/LinkedIn (pilares, research, diseño, publicación).
- `content/copywriting-breakthrough-advertising.md` — marco de persuasión (niveles de consciencia, madurez de mercado, 7 tácticas) a aplicar al escribir el guion de un carrusel.

## Convención

Cuando surja una decisión de arquitectura o proceso que valga la pena no repetir, documentarla en un archivo nuevo (`arquitectura-*.md` para temas técnicos, `content/*.md` para temas de contenido/marca) y sumarla a este índice.
